# КВАРТАЛ — агентство недвижимости

Сайт агентства недвижимости: каталог объектов с фильтрами, карточки объектов, агенты, заявки — и админ-панель для управления всем контентом.

## Стек

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4
- Prisma ORM + MySQL
- Аутентификация админки — сессия на подписанной cookie, пароли хешируются bcrypt

## Запуск локально

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` в корне проекта:
   ```
   DATABASE_URL="mysql://root:@localhost:3306/kvartal_realty"
   AUTH_SECRET="любая случайная строка"
   ```
   Нужна локальная MySQL с пользователем `root` без пароля (или поменяйте строку подключения под свою БД).
3. Примените миграции и заполните базу демо-данными:
   ```bash
   npx prisma migrate deploy
   npx prisma db seed
   ```
   Либо импортируйте готовый дамп `bd.sql` в MySQL напрямую.
4. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
   Сайт — [http://localhost:3000](http://localhost:3000)

## Структура проекта

- `src/app/(site)` — публичные страницы сайта
- `src/app/admin` — админ-панель (защищена логином, см. `src/proxy.ts`)
- `prisma/schema.prisma` — модели данных, `prisma/seed.ts` — демо-контент
- `bd.sql` — дамп MySQL-базы для быстрого импорта без сида
